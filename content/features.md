## Core Features

### GOAT Format Focus
A card pool and rule environment built around classic 2005-era Yu-Gi-Oh!, with the project organized around GOAT-legal cards and recognizable historical archetypes.

### Campaign Progression
NPC duelists are arranged through progression tiers, giving the game a sense of advancement instead of presenting every challenge at once.

### Pack Collection
Earn credits and open themed packs to grow a collection over time. Packs have distinct pools and unlock requirements, with a larger vault-style pool available as a special reward.

### CPU Duelists
Challenge CPU-controlled opponents using decks built around recognizable GOAT archetypes, from control strategies to burn, chaos, warrior, and more unusual builds.

### Retro Interface
The client uses a dark charcoal interface, warm gold accents, compact pixel-like typography, and menu layouts inspired by early-2000s game UI.

### Local-First Project
The project is designed to be straightforward to run and iterate on locally, making it easy to experiment with decks, NPCs, balance, visuals, and progression data.
