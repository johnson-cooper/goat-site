## FAQ

### Is this an official Yu-Gi-Oh! product?
No. Project Goat is a fan-made project and is not affiliated with or endorsed by Konami.

### What format does the project focus on?
The project is centered on **GOAT Format**, with its campaign, card pool, NPCs, packs, and deck library designed around that era of play.

### Is the website itself dynamic?
No. This showcase is intentionally static: HTML, CSS, JavaScript, images, video, and Markdown files only. It can be hosted free on services such as GitHub Pages or Cloudflare Pages.

### How do I edit the website text?
Open the files inside the `content/` directory and edit the Markdown. The browser loads those files when the page opens, so you do not need to rebuild the site.

### Can I add more screenshots?
Yes. Add images to `assets/images/`, then duplicate one of the gallery cards in `index.html` and change its image paths and caption.

### Can I replace the gameplay video?
Yes. Replace `assets/video/project-goat-demo.mp4` with another MP4 using the same filename, or change the source path in `index.html`.
